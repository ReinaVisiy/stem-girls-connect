# STEM Girls Connect
**Empowering the next generation of female STEM leaders**

## Mission
To bring together and empower girls and young women in STEM related fields.

## Vision
To close the gender gap in STEM fields by empowering and supporting girls and young women to explore, learn and succeed in STEM.

## Main Activities
- Advocacy
- Training Workshops
- Mentorship

## Built with
* **React** for a fast, modern user interface
* **TypeScript** for static typing
* **Vite** for a smooth development experience
* **Tailwind CSS** for responsive styling

## Getting Started
To run this project locally:
1. Clone the repository
2. Run `npm install`
3. Run `npm run dev`

To build for production:
```
npm run build
```
